# Robot Universals

**Status: skeleton only — table of contents and chapter subheaders, no prose yet (2026-08-07).**

**What this is:** the central, cross-project reference for robot meta-culture across the entire Tepenian
multimedia universe — this game, the Cryptograph Helix novels, the "Southern Lights" TV continuity, the
Outer Tepenia series, and anything set in this universe going forward. Any robot population, in any
Tepenia-branded work, should be writable as a specific variation on the floor this book establishes, never
a contradiction of it.

**Relationship to Donald E. Brown's *Human Universals* (McGraw-Hill, 1991):** this book borrows Brown's
methodology — the essence/accident distinction for judging what transfers between populations, the
Direct-Transfer / New-Universal / Non-Transfer classification scheme, and the general shape of "a floor of
what's true everywhere, plus a method for deriving what varies" — but is an original work about a robot
culture, not an adaptation or copy of Brown's own content. Where a chapter's reasoning leans on Brown's own
framework, it says so directly.

**Source material this book is compiled from** (raw working notes, not superseded by this book — this book
is the polished, authored version of what those files already established):
- `InnerTepeniaGDD/Neo-Races-and-Cultures/_Method/Human_Universals_Culture_Framework.md` — the full
  methodology and category-by-category walkthrough
- `InnerTepeniaGDD/Neo-Races-and-Cultures/_Method/Robot_Culture_Toolkit_Status_Reference.md` — the
  condensed at-a-glance snapshot of every resolved item
- `InnerTepeniaGDD/Neo-Races-and-Cultures/_Method/Robot_Culture_Open_Questions_Tracker.md` — the working
  checklist and the developer's own original notes on each resolved item
- `InnerTepeniaGDD/Worldspace/Robot_Biology_and_Culture/Robot_Physiology_and_Cultural_Practices.md` — the
  authoritative robot biology source file
- `Reference/Laws_of_Robotics.md` (this repo) — the Fundamental Laws themselves
- `InnerTepeniaGDD/Worldspace/Locations-and-Levels/Outside-World/Tepenian-Federation/Locations/Infrastructure/Arcanet.md`
  — the Arcanet's own dedicated reference file

**What this book deliberately does not contain:** any specific population's actual culture (a particular
Concordia district, a particular one of Inner Tepenia's 35 cities, a particular Cryptograph Helix-era
colony). That stays in each individual project's own repo. This book is the floor and the method — not the
catalog.
