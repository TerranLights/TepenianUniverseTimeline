# Enneagram Undercurrents

**Status:** established 2026-08-11, developer-originated concept — universe-wide, not specific to any one
project. Recorded here per `Repo_Scope.md`'s Enneagram exception: a character's confirmed Type and Undercurrent
are cross-media "Who" facts, shared identically across every sibling project.

**Full mechanics, the underlying Enneagram type library, and the book-mining methodology live in
`InnerTepeniaGDD/Worldspace/Enneagram/`** (see that folder's own `README.md` as the entry point, and
`Undercurrents.md` specifically for the complete write-up) — this repo does not duplicate that material, only
the shared concept and any confirmed per-character assignments.

## What an Undercurrent Is

A character's main Enneagram Type is the dominant profile that generally drives her. In addition, a character
can optionally carry a second, weaker Enneagram profile — an **Undercurrent** — a real Type complete with its
own Wing and Instinctual Subtype, sitting underneath the main Type rather than replacing or blending into it.

## Core Rules (summary — see the GDD file for full detail)

- **Not obligatory.** Only the main Type is required. An Undercurrent exists only where the evidence for a
  real, distinct second signature actually shows up — never hunted for as a mandatory pass.
- **Unrestricted by adjacency.** Unlike a Wing (locked to the two types adjacent to the main Type), an
  Undercurrent can be any of the other eight types.
- **A full profile of its own** — its own Wing and Instinctual Subtype, not a bare type number.
- **Relative strength — working baseline 80% Type / 20% Undercurrent.** A placeholder, not a locked mechanic;
  open to revision as actual development turns up a better way to model the interplay.
- **Occasional conflict is a feature.** The main Type and the Undercurrent can genuinely pull in different
  directions in specific moments — usable material, not something to resolve permanently.
- **Retroactive-eligible.** Can be added after the fact to a character whose main Type is already locked, if a
  genuine second signature is spotted in hindsight. Purely additive — never reopens the main Type.

## Why It's Recorded Here, Not Just in InnerTepeniaGDD

A character's psychology doesn't change depending on which sibling project (game, novel, TV continuity) is
currently depicting her — the same way her birthdate or her role in a shared historical event doesn't change.
Where a project-specific writing framework (KWML, Want-Need-Idea) is genuinely that project's own tool for
building prose, Enneagram type is being used as a portable, universal fact about the character herself. This
file exists so a confirmed Type/Undercurrent assignment for a shared character is discoverable from any
project without that project needing its own copy of the underlying Enneagram apparatus.

## Recording a Character's Type/Undercurrent

Same shorthand `InnerTepeniaGDD` uses: `Type: [Main Type]w[Wing] [Instinct] · Undercurrent: [Type]w[Wing]
[Instinct]`. Log confirmed cross-media assignments below as they're locked.
