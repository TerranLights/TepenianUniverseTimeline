# Chapter 19: Weighing the Axes

Chapter 18 formalized how the differentiation engine generates variation. This chapter formalizes something
narrower but just as practical: when a robot population's identity draws on more than one axis at once —
city, Build, Gen/Mark — which one actually carries the weight, and by how much. Chapters 13 and 14 already
answered this in the specific cases they covered. This chapter turns those specific answers into a general
default any future writer can start from.

## City/Locality as Dominant Weight

City and locality is the dominant axis, by a wide margin, and should be treated as the default starting
point for any robot population's identity. Chapter 13's own comparison — four humans of wildly different
physical types, all identifying overwhelmingly with their shared home city rather than with their own
bodies — established this concretely, and the same logic transfers directly to robots. When building a new
population, city/locality is where identity, shared struggle, and cultural character should be anchored
first.

## Build as Locality-Tied, Secondary

Build contributes real physical variety, and can even carry genuine functional specialization tied to a
locality's own economic character (Chapter 3). What it does not contribute is an identity axis independent
of city/locality. Because Build is itself locally driven, it should be treated as secondary and derivative
— an expression of the same city/locality tie, not a competing source of identity running alongside it.
A population's characteristic body types are worth establishing for texture and plausibility, but they
should never be asked to carry the identity weight that city/locality already carries.

## Gen/Mark as Low-Weight but Structurally Independent

Gen/Mark is real, and it is the one axis genuinely independent of city (Chapter 14) — but it should still be
weighted lightly as an identity source. It is useful for cross-cutting material: a generational character
trait, a plot hook tied to which Mark produced a given robot, a moment of recognition between robots who
share a Gen despite coming from entirely different cities. It should not be treated as a strong identity
anchor the way city/locality is. Gen/Mark's real independence from city is a structural fact worth using
deliberately — it is not, on its own, a reason to give it more felt weight than robots themselves actually
give it.

## Judging Relative Weight for a New Population

The practical default, for any new robot population — a new city in a future DLC, a Cryptograph Helix-era
colony, an Outer Tepenia settlement — is to weigh city/locality first and heaviest, Build second as an
expression of that same locality rather than an independent axis, and Gen/Mark last and lightest: real,
usable, but rarely load-bearing for identity.

This is a default to depart from deliberately, not a rule to break accidentally. A future writer may have a
genuine narrative reason to give Gen/Mark unusual identity weight for a specific population, or to make
Build carry more felt significance than it typically does. That remains a legitimate creative choice. What
this chapter asks is that any such departure be a conscious one, made with the default in view and set
aside on purpose — not an unexamined default in its own right, arrived at simply because nobody weighed the
axes in the first place.
