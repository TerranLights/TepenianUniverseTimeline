# Doll-to-Living Height Transposition

**Status:** established 2026-09-18, developer-originated concept — universe-wide, binding across every sibling
project per `Repo_Scope.md`'s "Who" category (a physical identity fact about a character, the same status as a
confirmed Enneagram Type — see `Enneagram_Undercurrents.md` for the precedent this follows).

## The Concept

Every robot/Doll character in this universe is a "robotification" of an actual, real-world sexdoll that exists
in reality — not an invented physique. Translating a real-world doll's physical measurements into how that
character should be understood/described in-universe, as a living person rather than a manufactured object,
requires deliberate artistic liberties, not a literal 1:1 metric conversion.

## The Real-World Baseline

- **General majority of real-world full-body sexdolls: roughly 158–165 cm.**
- **Short end (full-body, not torso-only dolls): down to ~140 cm.**
- **Tall end: up to the 170s cm.**

## The Transposition Rule

The doll-world's own "typical/majority" range (158–165 cm) maps onto what should read as a **"normal" height
range for human women** in-universe: roughly **5'5" to 5'9"** (~165–175 cm). This is not a literal unit
conversion — the doll-typical range is deliberately mapped onto a *taller* human-height band than its literal
metric equivalent, so the in-universe female height distribution as a whole reads taller than real-world human
averages by design. A given Doll's position within the real-world doll-height distribution (short end,
typical/majority, or tall end) should be translated onto the *equivalent relative position* within this
in-universe human-height band, not computed by direct metric conversion.

## How to Apply

1. Get the character's real-world reference doll's actual height (from its retail/catalog listing).
2. Place that height within the real-world distribution: short end (~140 cm), typical/majority (~158–165 cm),
   or tall end (~170s cm and up).
3. Translate that relative position onto the in-universe human-height band (~5'5"–5'9" as the "normal" range,
   scaling proportionally above and below for dolls outside the typical range) — not a literal metric
   conversion.
4. The exact resulting figure is ultimately an authorial call, not a mechanically derived number — this method
   establishes the right *range* and relative positioning; the author picks the specific value that feels right
   for that character.

Confirmed per-character applications of this rule are recorded in each character's own project-specific file,
not duplicated here — this file holds the shared method only.
