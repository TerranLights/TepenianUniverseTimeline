# Character Development Methodology — Stage 3: Character Data

**Pipeline position:** turning the processed information from Stage 2 (`02_Information_Processing.md`) into
actual usable character data — the structured fields a finished character psychological profile should
contain. Distinct from a project's own surface/mechanical stat sheet, if it has one (see `../Templates/`) —
this is the deep layer.

**Status:** vocabulary consolidation, the per-character fill-in worksheet (tier determination, fill-in order,
Stage 2 cross-references), and the Front-Gate/Character Hierarchy resolution are all in place.

---

## Step Zero: The Front-Gate Question — does this character need the full node set?

Before filling in anything below, decide how much of Stage 3 a given character actually warrants. This isn't
a node itself — it's a calibration step that governs how much of the rest of this stage to actually do.

- **Drift vs. Drive** — most characters, including most background/walk-on figures, don't have Drive; they
  have Drift (path-of-least-resistance, passively made decisions). A Drift character works fine in a bit part
  but is fatally weak as a protagonist or major character.
- **Character Hierarchy** (walk-on / minor / major — filed under Stage 4, cross-referenced here) is the
  structural-weight counterpart: Drift/Drive tells you how much internal engine a character needs; the
  Hierarchy tells you how much narrative weight she's carrying. Read them together.
- **Practical rule:** a walk-on/Drift-type character may only need the Ghost and Want nodes filled in, not the
  full set below. Full-principal and major-supporting-character status is what earns the complete node set.

## Consolidated Core Nodes

Writing-craft literature contains at least six different named systems all describing the same underlying
Want/Need/Ghost/Lie territory, using different vocabulary for overlapping concepts (a Lie/Want/Need/Ghost/
Truth framing; a Goal/Desire/Lesson framing; a Goal-Motivation-Conflict framing with an External/Internal Goal
and Greatest Fear; a Strength/Longing/Fear framing; a Purpose/Motive and Direction/Goal/Drive/Attitude framing;
plus an original Desire/Need split from a different source still). Below is the reconciled set — one canonical
node per real concept, with every source vocabulary that maps onto it named explicitly so nothing gets
silently lost, whichever specific craft book or system you happen to be drawing from.

### NODE: Want (External Goal)

The concrete, external, plot-level thing she's pursuing. Keep a built-in two-level split rather than
flattening this to one field:
- **General Goal** — the whole-arc throughline (survive the threat, restore the status quo).
- **Immediate Goals** — the scene-by-scene sub-goals in service of the General Goal.

### NODE: Need / Truth (Internal)

The corrective belief that cures the Lie. "The Lesson doesn't have to be learned, and doesn't have to be
positive" is the same claim as the Negative Arc taxonomy (Disillusionment/Fall/Corruption, see Stage 5) stated
in different words — not additional content, just confirmation from a second angle.

### NODE: Lie / Flaw

A wound-rooted false belief that actively blocks the Want. A Flaw-vs-Personality-Trait diagnostic test
survives as a useful question (see Standalone Fields, below), but Flaw itself is not a separate field from
Lie — it's the same node under a different name.
- **Romance sub-case:** "I can't love him because ___" is a quick-fill variant of this exact node, scoped
  specifically to what blocks the internal conflict for a romanceable character. Use it as a fast draft-
  starter for the Lie/Flaw node when the character in question is a romance option, not as a separate field.

### NODE: Ghost (Backstory Wound)

The past wound that explains *why* she believes the Lie. **The Five Fundamental Types of Death** (Social /
Spiritual / Psychological / Professional / Physical) stays attached here as a checklist applied *to* this
node, not a separate field: when building a Ghost, name which of the five types of death is actually in play.
- **Proportionality rule:** the bigger the Ghost, the bigger the Lie, the bigger the arc — calibrate the wound
  to the scale of transformation the arc is actually meant to deliver.
- **Reveal-timing is a separate decision**, not part of the node's content: gradual reveal, origin-prologue
  (the Ghost dramatized as its own opening sequence), or never revealed at all are all legitimate — decide
  deliberately per character rather than defaulting to one.

### NODE: Desire / Motive (the emotional connector)

**Terminology collision, worth stating plainly so it's never silently misapplied:** in some source material,
"Desire" is internal (the emotional charge behind the Want); in other source material, "Desire" is external
and equals the Want node above. Same word, opposite referent, two unrelated usages across different craft
books. Once disambiguated, this node is genuinely additive — none of the other core terms separately name
"the emotional charge that makes the Want matter this much, usually traceable back to the Ghost." Use the
**Why Chain** (Stage 2 — keep asking "why does she want this" past the first, obvious answer until it becomes
primal) as the construction technique for this node; it's listed under Stage 2 as a processing tool, but its
*output* is what fills this field.

### NODE: Greatest Fear

What she is most afraid will happen or be revealed. Feeds directly into low-point/climax construction in
Stage 5 — the standard rule: a character's low point should be engineered to match this specific, already-
established fear precisely, not just be "something bad."

### NODE: Background Taxonomy (Body / Environment / Experience / Ideas)

A four-part taxonomy is the recommended canonical form here; a competing three-way Physical/Psychological/
Sociological split from a different source maps onto three of the four (Physical→Body, Sociological→
Environment, Psychological→roughly Experience), but has no slot for the fourth category, **Ideas** (exposure
to a specific belief system, philosophy, book, speech, or person's worldview as its own independent shaping
force, distinct from lived experience or trauma) — worth keeping as its own explicit slot, especially in any
setting with a rich religious/philosophical landscape (competing belief systems, ideologies, or worldviews
available to draw from — see `01_Input_Information.md`'s A6 for what this looked like in one real setting).
- **Experience carries its own sharp caution, worth keeping attached to this node**: it is not the objective
  event that creates the psychological effect, it's the character's individual interpretation of and reaction
  to it — two characters sharing a structurally similar backstory template (war orphan, exile, refugee) should
  be built to react to it in genuinely different ways, not just relocated to different settings.

## Fields That Stay Standalone

Genuinely distinct information, not redundant with any node above:

- **Strength** — a positive, competence-based trait shown independent of her wound or her goal. Worth an
  explicit "what is she good at, apart from what hurts her" field, since it's easy to skip.
- **Reasons She Can't Quit** (External / Internal) — a commitment/stakes mechanism, distinct from goal-
  content: External (a literal constraint forces continued engagement) and Internal (named psychological
  compulsions — Pride, Shame, Duty, Gratitude, Loyalty).
- **Dominant Attitude + Contradictory Exception** — a habitual, not-necessarily-rational disposition toward a
  topic, plus exactly one narrow, genuine exception to it that only surfaces under a specific, plantable
  circumstance. A controlled inconsistency, not a random one.
- **Character Trait vs. Personality Trait** — a second, unrelated axis from Lie/Flaw: character traits
  (honesty, loyalty) come from morals/values/upbringing and are often hidden until tested; personality traits
  (bubbly, dour) are outward, often deliberately performed projection. A character can perform a personality
  trait that actively conceals a contradictory character trait.
- **Coping / Defense Mechanism (tiered)** — a four-tier hierarchy (Psychotic / Immature / Neurotic / Mature).
  Note: core desire and secondary desires can call on genuinely different tiers — a character can be Mature-
  tier in one domain and Immature-tier specifically where her core wound is implicated, and that asymmetry is
  itself real characterization, not an inconsistency to smooth over.
- **Speech-Pattern Correlation Table** — a diagnostic *output* field: once the Ghost and self-esteem level are
  fixed, dialogue patterns across every scene should be checkable against a correlation table (hesitant/
  evasive for past failure, bitter/talking-down for someone burned before, etc.) rather than invented fresh
  for a "good line" each time.
- **Personality-type assignment (type / wing / instinct, or the equivalent for whatever system is in use)** —
  stays the mandatory, primary motivational axis. See the sibling `../Enneagram/` folder for this Pipeline's
  own default system's full reference material.
- **Direction — the Five Wishes** (Adventure / Security / Recognition / Response / Power) — an optional
  *secondary* motivational lens. Deliberately not merged into the personality-type assignment: the type
  assignment asks about core fear/desire structure and coping style; Direction asks what *style of life-
  fulfillment* she's chasing. Different question. Use when the type assignment alone doesn't fully explain a
  specific goal-orientation pull, not as a mandatory field.

## Diagnostic Tests (not fields — questions to run against the nodes above)

- **Flaw vs. Personality Trait test:** does this behavior come from an unhealed belief that costs her
  something structurally important (→ belongs in Lie/Flaw), or is it just color (→ belongs in the Character
  Trait / Personality Trait fields)? A trait can graduate into a flaw if it turns out to be load-bearing; most
  never do, and that's fine.

## Coverage Checklists (two, doing genuinely different jobs)

Three different "have I covered everything" checklists exist across writing-craft literature. They don't all
do the same job, so they aren't fully consolidated here — but one is a strict subset of another and is
downgraded accordingly:

- **The 12-Category Character Notebook** — the broadest of the three; recommended as the **master content
  checklist**. Categories: Basic Headline, Basic History, Archetypal/Category/Stereotypical Resonance, Actions
  and Reactions, Moral Valence, Dreams and Ambitions, Inner Life, Shadow Sides and Difficulties in Living,
  Consequences of Upbringing, Power/Sexual Potency/"Alpha-ness," Cultural Component, Meaning Web.
- **Backstory's Five Slots** (Belief System, Values, Family and Friends, Fears and Phobias, Prime Motivating
  Incident) — **an explicitly-named fast-pass subset of the 12-Category Notebook**, not an independent tool.
  Use it when a quick first pass is needed and the full notebook is overkill.
- **The Ten Ways We Come to Know a Character** (Action, Motive, the Past, Reputation, Stereotypes, Network,
  Habits and Patterns, Talents and Abilities, Tastes and Preferences, Body) — **kept fully standalone**. This
  answers a different question from the other two: not *what content exists* about her, but *how will the
  audience actually learn it on-screen*. Run this checklist after the notebook is filled, as a delivery-
  channel audit, not a content-generation pass.

## Content Library, Not a Vocabulary — Flagged So It Isn't Mistaken For One

- **A Life Arc archetype set** (this system used a six-archetype set — Maiden/Hero/Queen/King/Crone/Mage) is
  **pre-built content that plugs directly into the already-consolidated Want / Need-Truth / Lie-Flaw nodes
  above** — each archetype comes with its own ready-made thematic Lie/Truth pair. It is not a seventh
  competing triad. When a character's existing material already gestures toward one of the life-stages in
  whatever archetype set you're using, use its pre-built Lie/Truth pair to seed the Lie/Flaw and Need/Truth
  nodes rather than inventing from scratch — and check whether her existing material instead points toward a
  Shadow Archetype for a compromised/negative-arc character, if your archetype set has one. **If more than one
  archetype or Lie/Truth hypothesis was genuinely in contention before one was picked, don't just drop the
  runners-up** — see `../Design_Principles/Preserve_Unchosen_Material.md`; a rejected reading of the same raw
  material is often exactly right for a different character built later.

## The Per-Character Fill-In Worksheet

This is what actually turns the reconciled vocabulary above into a usable, ordered process — resolving the
Front-Gate's binary Drift/Drive split against the three-tier Character Hierarchy (Stage 4), since a real
worksheet needs to know what a *minor* character gets, not just walk-on-vs-major.

### Tier determination

| Tier | Mandatory fields |
|---|---|
| **Walk-on** (Drift) | Ghost + Want only |
| **Minor** | Ghost + Want + Lie/Flaw + Need/Truth + Desire/Motive + Greatest Fear — the complete core wound-and-belief cluster, nothing supplementary |
| **Major** (Drive) | Everything — core cluster + all standalone fields + full coverage checklists + Life Arc content-library check + Speech-Pattern Correlation Table |

### Fill-in order for the core cluster

Based on the causal relationships already established when these nodes were built — Ghost causes Lie, Desire/
Motive connects Ghost/Lie to Want, Need/Truth is defined as the corrective opposite of whatever Lie turns out
to be:

1. **Ghost** first — the root; everything else is either caused by it or defined in contrast to it.
   *Stage 2 cross-reference: Self-to-Character Memory Mining, mode (a) — the fixed question set.*
2. **Greatest Fear** next, while the Ghost is fresh — tightly coupled to the wound (what she's afraid will
   happen again).
3. **Lie/Flaw** — the false belief the Ghost produced.
4. **Desire/Motive** — the emotional connector *from* the Ghost/Lie *to* the Want; has to come after Ghost/Lie
   and before Want for exactly that reason.
   *Stage 2 cross-reference: The Why Chain — its output is literally what fills this field.*
5. **Want** — now groundable in something, rather than picked arbitrarily.
6. **Need/Truth** last — defined as the corrective *opposite* of whatever Lie/Flaw turned out to be, so it
   can't really be filled in first.
   *Cross-reference: check the Life Arc content library first — a pre-built Lie/Truth pair may already fit
   and can be seeded here instead of built from scratch.*

### Major-tier supplementary fields

No strict order required; filled in after the core cluster:
- **Background Taxonomy** (Body/Environment/Experience/Ideas) — mostly assembly, not diagnostic.
- **Strength.** *Stage 2 cross-reference: the Scenario Diagnostic Template, run on a competence-testing
  situation.*
- **Coping/Defense Mechanism tier.** *Stage 2 cross-reference: Self-to-Character Memory Mining, mode (b) —
  the single-charged-moment version.*
- **Reasons She Can't Quit, Dominant Attitude + Exception, Character Trait vs. Personality Trait.** *Stage 2
  cross-reference: Compare-and-Contrast Self-Image, or the In-Voice Character Interview for the harder-to-
  access ones.*
- **Direction** — only if the personality-type assignment alone doesn't explain a specific goal-orientation
  pull.

### Closing passes, major tier only

1. Run the **Flaw vs. Personality Trait test** against everything gathered.
2. Run the **12-Category Notebook** as a completeness check, then the **Ten Ways** checklist as a delivery-
   channel audit.
3. Build the **Speech-Pattern Correlation Table** last — a diagnostic *output*, derivable only once the Ghost
   and self-esteem level are actually fixed.

## A Note on the Front-Gate / Character Hierarchy Split

Worth keeping deliberately unmerged, not an oversight: Stage 4 has its own fully-sequenced Front-Gate trio
(MICE Quotient → Character Hierarchy → Story Problem vs. Character Problem), each step there doing a distinct
job specific to *narrative role and story investment*. Pulling Character Hierarchy into this file would break
that sequence for no gain — this stage's Drift-vs-Drive front-gate serves a genuinely different, narrower
question (how much *psychological engine*, i.e. how much of the node set above, a given character needs), not
how much narrative weight she carries. The two front-gates are related and worth reading together, but they
belong to their respective stages and should stay cross-referenced rather than consolidated.
