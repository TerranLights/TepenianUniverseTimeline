# Design Principle — Placeholder Naming Convention

**What this is:** a lightweight, consistent folder/file-naming practice for tracking characters and figures
whose names are AI-generated or otherwise provisional, so a large cast never quietly accumulates unflagged
placeholder names that later get mistaken for deliberate, finalized choices.

---

## The Convention

Any character or named figure whose name isn't yet a deliberate, finalized choice gets a bracketed marker
worked directly into her folder or file name — something in the shape of:

```
TBN [SERIES-CODE brief-descriptor Working-Name]
```

— a "To Be Named" tag, a short internal reference code if the project uses one, a brief descriptive phrase,
and the actual working name currently in use. Inside the character's own profile document, the header repeats
this flag explicitly (e.g. "## TBN (designation: XT-30) / 'Luna'"), and any open-questions or design-notes
checklist includes an explicit line item to replace the placeholder name if and when a real one is chosen.

## Graduating Out

A character graduates out of the "TBN [...]" bracket once she has real, developed content attached to her —
at that point, the folder is renamed to drop the bracket and the working name (or a newly chosen one) becomes
the character's actual name going forward. A character who's graduated but whose name is still explicitly
provisional can keep a lighter marker in her own header (e.g. "placeholder name — permanent name TBD")
without needing the full bracketed folder convention anymore.

## Why This Matters at Scale

For a small cast, an unnamed or provisionally-named character is easy to remember and track informally. For a
large cast built incrementally over a long production, provisional names silently calcify into de facto
canon if nothing marks them as still-open — a later contributor (or the same author, much later) has no way
to tell "this name was a deliberate choice" from "this name was never revisited" without some standing,
consistent signal. The bracketed convention above is that signal: cheap to apply consistently, and impossible
to miss when scanning a folder listing.
