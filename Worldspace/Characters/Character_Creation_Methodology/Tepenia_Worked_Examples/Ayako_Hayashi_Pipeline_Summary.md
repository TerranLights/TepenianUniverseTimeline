# Worked Example: Ayako Hayashi (Full Five-Stage Run)

**A note on this file's provenance, honestly stated:** unlike the Calethina case study, no single already-
written document walks through this run stage by stage — this summary is reconstructed from the working
notes taken at the time the run was performed, not copied from one source file. If deeper original detail is
ever wanted, the two places to look are Ayako's own character files in the source project and that project's
own running record of this run. Nothing below should be treated as more authoritative than that original
material — this is a summary of it.

**Why a second full run matters, and why it's included here at all:** one worked example can always be a
coincidence — a case that happens to fit the tools because it was picked for fitting them. This run was
deliberately chosen to test the opposite: Ayako was one of three characters already carrying essentially all
the Stage 1 information a full run needs, identified during an ordinary cast survey, not hand-picked to
flatter the methodology. What a second, independently-run character confirms is worth more than what a first
one merely suggests.

---

## Setting Context, Briefly
Ayako Hayashi is a supporting character with her own personal arc in the source project — a more structurally
typical character than Calethina (an ordinary figure in the protagonist's life, not an exempt narrator-type),
which is itself part of why this run is a useful complementary data point.

## Stage 1 — Input Information
Cleared the intake process with **zero clarification questions generated** — a clean pass through the Three-
Part Surfacing Test, with only one low-stakes proposed default surfaced (a placeholder detail never actually
stated in her file). This is itself a data point: it confirms the intake stage correctly recognizes when a
character already has enough established material to skip the clarification loop entirely, rather than
generating questions for their own sake.

## Stage 2 / 3 — Processing and Character Data
**New interpretation, not yet canon**, generated by running the diagnostic toolkit against her established
material rather than stated anywhere in her own files:

- **Lie/Flaw hypothesis:** *"I am only safe to love, and only worthy of connection, if I remain flawlessly
  vigilant — the moment I let my guard down, someone I love dies."*
- **Need/Truth hypothesis:** connection doesn't require perfect vigilance; she's allowed to be ordinary, even
  to fail sometimes, and still be worthy of love.
- **Coping/Defense Mechanism — a genuine two-tier-by-domain finding.** Her established behavior reads as
  Neurotic-tier (controlled withdrawal) in ordinary social contexts, but Mature-tier sublimation specifically
  in crisis contexts tied to her professional role — a real, independently-arising instance of the diagnostic
  toolkit's "different tiers can apply in different domains for the same character" principle, not something
  engineered to demonstrate it.
- **A real-world-archetype psychological parallel**, checked rather than assumed: a Snow Queen shadow-state
  parallel fits her stated Emotional Core unusually precisely — her redemption is catalyzed externally, and
  needs to be "thawed" by someone choosing to fight for her — without necessarily importing that archetype's
  full beat template, which doesn't fit her personal-scale conflict as cleanly as the underlying psychology
  does. Worth noting as a general caution: a strong psychological-parallel match doesn't automatically mean
  the whole structural template that parallel comes from should be imported too — check the two separately.

## Stage 4 — Story Material: A Genuine Structural Variant
Her Impact Character/Revenant casting is the most load-bearing finding of this run, precisely because it does
**not** repeat Calethina's pattern. Rather than a single figure converging both roles, her casting **splits
across two different figures**: a person in her present-day professional life (whose situation echoes her own
original formative crisis) sits in the **Revenant** role, while the **protagonist** — specifically if the
deepest relationship track is pursued — sits in the **Impact Character** role. Confirming that the methodology's
tools support this genuinely alternate, equally valid configuration — not just a variation on Calethina's
single-figure convergence — is exactly the kind of result a second independent run is supposed to be capable
of producing.

## Stage 5 — Beats, Paths & Results

- **Inciting Event and First Plot Point already fully established, independently, before this run touched
  them.** Both are already-written canon (a categorical professional recusal tied to a conflict of interest),
  and the beats this methodology would have proposed matched what was already on the page — a confirmation
  case, not a design intervention, worth recording precisely because not every run needs to fix something to
  be useful.
- **A second, independent real-world confirmation of the Disillusionment "straddle" case** in the Ending-Shape
  Cross-Mapping Table (see the necessity-branch discussion in `Calethina_Case_Study.md`). Her own file states,
  in language written independently of this methodology, that there is no single clean resolution to her core
  grief — the meaningful variation lies in how she integrates it, not in a success/failure axis. This is the
  same wins-internally/something-still-stays-lost shape Calethina's edge case surfaced, arrived at by a
  completely separate character's design pass — the difference between "this framework has an edge case" and
  "this framework has a *recurring, real* edge case" is exactly this second confirmation.
- **A complete secondary mini-arc, stacked after her base arc**, gated behind a high standing on two separate
  emotional-tracking axes at once (a grief axis and a bond axis), if the medium tracks relationship state this
  way. It carries its own three-beat internal structure (Discovery → Presence Beat → a deliberately non-clean,
  three-way Resolution). Its Presence Beat is explicitly written to *mirror* — not repeat — the base arc's
  Emotional Core: a real, independently-written instance of Chiastic Mirroring's "comparative symmetry, not
  sameness" principle (see `../Pipeline/05_Beats_Paths_Results.md`).
- **A distinct branching mechanic, worth keeping conceptually separate from the Trigger-Type Design Pattern.**
  Her arc has thirteen total investigation routes — five ability-based, eight based on the state of the wider
  world — which is a different axis of variety from trigger-type variety: trigger-variety governs *entry* into
  an arc (see `../Design_Principles/Trigger_Type_Pattern.md`); this approach-variety pattern instead governs
  *how the middle of an already-entered arc gets investigated*. Both patterns can coexist on the same character
  without conflicting, but they answer different design questions and shouldn't be collapsed into one concept.

## Observed, Not Yet Acted On
Her own file notes that several other characters' personal arcs "run through their work rather than beside
it" — one through a central investigation, one through an infrastructure-focused thread, one through a
performance/artistic thread. This is a real cross-cast design tendency worth being aware of, but it's flagged
here only as an observation, not elevated into a standing rule — that would need a dedicated read across the
full cast before it's safe to generalize.

## What This Second Run Actually Validated
The two-tier-by-domain Coping Mechanism finding and the split Revenant/Impact-Character casting both show the
methodology's tools producing genuinely different, non-templated outputs when applied to a genuinely different
character — the opposite of a tool that just returns the same answer shape regardless of input. The Inciting
Event match against already-written canon shows the tools can correctly recognize "nothing needs fixing here"
and not manufacture problems to justify their own use. And the second Disillusionment-straddle confirmation is
the single most valuable finding of this run: it's the difference between a documented framework limitation
and a documented framework limitation confirmed to recur.
