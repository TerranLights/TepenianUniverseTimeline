# Universal Design Laws

**What this section is:** the author's design laws that bind **everything**: characters, locations, objects, organizations, events, in every Tepenian Universe project and medium (games, novels, TV, film, music). A law here is not a project's preference or one book's craft choice. It applies wherever the universe is built.

**Why it lives in this repo:** the author created this section on 2026-10-29. Because these laws shape every "who" and "where" this repo records, they sit beside the canon they govern. This is an explicit exception to `Reference/Repo_Scope.md`, which records it.

**How a law is recorded here:** one file per law. Each file gives:
- the **status line** (binding; date; scope);
- **the law** itself;
- **why** (the author's reasoning);
- **how to apply** it;
- a **self-check**.

When an existing project file conflicts with a law here, the law wins. The conflict is flagged for the author, not silently resolved.
